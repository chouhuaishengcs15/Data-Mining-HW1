## 投影片架構

| #     | 內容                                                            | 講者 |
| ----- | --------------------------------------------------------------- | ---- |
| 1     | Title & team                                                    | W1   |
| 2     | Motivation                                                      | W1   |
| 3     | Problem formulation                                             | W1   |
| 4–5   | Data & key EDA insight                                          | W2   |

每張投影片的講者備註都有講稿重點與建議秒數。
