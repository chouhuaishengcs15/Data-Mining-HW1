# Notebooks

Coding Team notebooks should be stored here.

Planned structure:

- `01_data_preprocessing.ipynb` — P1: Data & Validation
- `02_eda_feature_engineering.ipynb` — P2: EDA & Feature Engineering
- `03_model_evaluation.ipynb` — P3: Model & Evaluation

## Rules

- Do not use the final test set for exploratory analysis or model selection.
- Keep notebook outputs understandable and reproducible.
- Use clear markdown headings to explain each major step.
- Avoid uploading temporary or duplicate notebook versions.
